# Submission checklist

- [ ] Install dependencies and start the app locally.
- [ ] Test the complete product → stock → bill → sales workflow.
- [ ] Run automated tests and review any failures.
- [ ] Capture genuine screenshots from your own running app.
- [ ] Record a 2–3 minute screen demo using `DEMO_SCRIPT.md`.
- [ ] Create a GitHub repository or submit the source ZIP as instructed.
- [ ] Update the AI/tools disclosure in `README.md` to match what you actually used.
- [ ] Personalise the project, understand the code, and practise the viva questions.
- [ ] Remove any local database file if it contains data you do not want to submit; it is ignored by Git.
